# 01 · Loop 到底是什么：手动喂 vs 让它自己转

**目的**：给后面七篇做基线对照。同一个小需求，分别用「一句一句喂」和「给目标 + 检查命令后放手」两种方式完成，看人要介入多少次。

**任务**（两种方式用同一个）：给 `CheckoutService` 增加「单笔订单最多 99 件商品，超过返回 422」，并补测试。

**方式 A：手动对话**：在 Agent 里正常聊，每次它停下来你再喂下一句。记录你发了几条消息。

**方式 B：最小 loop**：只给一句话加一个检查命令：

```text
实现：单笔订单商品总件数 > 99 时 quote 抛 IllegalArgumentException（HTTP 422），补单测。
完成标准：./mvnw -B verify 通过。没通过就继续修，通过后停止。
```

**记录**：人工消息数、总耗时、是否一次通过 verify。

> 文章里「人当瓶颈」的真实场景由作者补充，这里只提供可复现的对照任务。
